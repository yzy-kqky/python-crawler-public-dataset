# Python 公开网页文本采集 & 数据集构建项目
> 本项目仅用于软件工程课程学习，所有采集内容均来自公开网页，严格遵守robots协议，不爬取登录内容、个人隐私信息。

## 项目简介
使用Python requests + BeautifulSoup实现公开网页文本抓取，完成数据清洗、去重，将结构化数据存入MySQL数据库，输出整理后的文本数据集。

## 技术栈
- Python 3
- requests、BeautifulSoup4 网页解析
- MySQL（基础增删改查，存储采集数据）

## 项目流程
1. 目标网页筛选，确认网页允许公开采集
2. 爬虫脚本获取网页文本，设置请求延时，降低服务器压力
3. 数据清洗：去除无效标签、空文本、重复内容
4. 将清洗完成的数据入库保存
5. 输出数据集，撰写数据质量说明文档

## 项目产出
1. 爬虫采集脚本
2. 数据清洗代码
3. MySQL入库SQL语句
4. 数据集说明文档
